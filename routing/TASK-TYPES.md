# TASK TYPES

Determine task type before execution.

Allowed task types:

UX

Purpose:
Design screens and interactions.

Examples:

* create wireframe
* improve room flow
* review onboarding

Output:
UX proposal

---

PRODUCT

Purpose:
Define product behavior.

Examples:

* update PRD
* define feature
* change business logic

Output:
Product decisions

---

ENGINEERING

Purpose:
Implement code.

Examples:

* build component
* implement formulas
* connect screens

Output:
Files changed

---

ESTIMATION

Purpose:
Define calculations.

Examples:

* pricing
* labor
* ranges
* formulas

Output:
Calculation updates

---

RESEARCH

Purpose:
Explore unknowns.

Examples:

* benchmark
* compare
* validate assumptions

Output:
Recommendations

---

TESTING

Purpose:
Validate system.

Examples:

* QA
* edge cases
* acceptance criteria

Output:
Issues and validation
