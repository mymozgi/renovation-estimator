# RESEARCH

Goal:

Collect pricing and market data required to build the estimation engine.

Activities:

* define labor rates per finish type:
  * walls: painting, wallpaper, decorative plaster
  * floors: laminate, tile, vinyl
  * ceilings: paint, stretch ceiling, drywall
* define material cost ranges per quality tier (Economy / Standard / Premium)
* define surface preparation costs per condition level:
  * walls: ready / primer needed / putty needed / full preparation
  * floors: ready / leveling needed
* define regional labor multipliers for Warsaw, Kraków, Wrocław, Gdańsk, Poznań, Other city
* define supporting materials overhead (% of base materials cost)
* define window and door area deduction values (m² per unit)
* validate all PLN/m² ranges against current Polish market

Output:

pricing data tables ready for calculation engine

Validation:

all estimation inputs are defined — no placeholder values remain
